🤔 What Is nodal-agentos?

nodal-agentos is a desktop application that acts like an operating system for your AI agents. If you use Claude Code to help you write code or complete tasks, nodal-agentos gives you a clear dashboard to plan what needs to be done, send those tasks to Claude Code agents, and watch their progress in real time across all your projects.

Think of it as mission control for your AI helpers. Instead of juggling multiple terminal windows or trying to remember what each agent is working on, you get one clean view of everything happening. It's like having a project manager, a task board, and a live status screen all in one app.

✨ Why You'll Love It

  • 📝 Plan Your Work: Create task lists for any project. Break down big goals into small, actionable steps that your agents can tackle one by one.
  • 🤖 Delegate to Claude Code: With a single click, hand a task over to Claude Code. The agent picks up the work immediately and starts executing.
  • 👀 Follow Live Progress: Watch the agent's actions in real time. See what files it's changing, what commands it's running, and what it's thinking as it works.
  • 📁 All Projects in One Place: Whether you're working on three projects or thirty, nodal-agentos keeps everything organized. Switch between projects without losing track of any agent's work.
  • 🔧 Built for Real Workflows: It integrates with Git worktrees so you can test changes safely, and connects with Linear to sync your issue tracking.

nodal-agentos is currently built for macOS. To run it smoothly, your computer should have:

  • macOS 11.0 (Big Sur) or later
  • 4 GB of RAM (8 GB recommended)
  • 500 MB of free disk space
  • An Apple Silicon (M1/M2/M3) or Intel processor

⚙️ How It Works

nodal-agentos is built on modern technology that makes it fast and reliable:

  • Rust + Tauri: The core engine is written in Rust using Tauri, which means it's lightweight, secure, and uses minimal system resources.
  • React + TypeScript: The user interface is built with React and TypeScript, giving you a smooth, responsive experience.
  • SQLite Database: Your tasks and agent data are stored locally in a SQLite database. Everything stays on your machine, private and offline-friendly.

📖 How to Use It (Quick Tour)

  • Create a Project: Launch nodal-agentos, click "New Project," and give it a name. Point it to your existing repository or start fresh.
  • Add Tasks: Inside your project, click "Add Task." Write a clear description like "Fix login bug" or "Add tests for the payment module."
  • Assign to Agent: Click the agent icon next to your task. Claude Code will pick it up and start working.
  • Watch Live: The dashboard updates in real time. You'll see logs, file changes, and status updates as the agent works.
  • Review Results: When the agent finishes, you'll get a summary. Approve changes, merge branches, and move on.

📚 Frequently Asked Questions

Q: Do I need to know how to code to use this?

A: Not necessarily. The app is designed to be visual and simple. However, having Claude Code installed and configured will help. The interface is friendly enough for anyone comfortable with basic computer tasks.


Q: Is my data safe?

A: Yes. Everything is stored locally in a SQLite database on your machine. Nothing is sent to the cloud unless you explicitly use features that require it.


Q: Can I try it on Windows?

A: Currently, nodal-agentos is available only for macOS. Windows and Linux support are planned for future releases.
